# Casos de uso

| Ator | Caso de uso | Resultado |
| --- | --- | --- |
| Visitante | Navegar pelas coleções e destaques | Visualiza o catálogo |
| Visitante | Criar conta e entrar | Obtém sessão de cliente |
| Cliente | Adicionar produto ao carrinho | Item é registrado no carrinho |
| Cliente | Finalizar pedido e pagar | Pedido é criado para acompanhamento |
| Cliente | Consultar pedidos | Visualiza detalhes e status |
| Administrador | Gerir produtos e categorias | Catálogo é atualizado |
| Administrador | Gerir clientes e pedidos | Operação da loja é acompanhada |

Fluxo principal: navegar → adicionar ao carrinho → informar dados → pagamento → confirmação → acompanhar pedido.
